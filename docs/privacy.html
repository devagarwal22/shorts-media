ShortsFactory – Privacy Policy

Last updated: 30 September 2026

ShortsFactory ("the tool") is an internal publishing tool operated by Dev Agarwal ("we"). It is used only to publish videos we produce to YouTube channels we own and manage. It has no public users.

YouTube API Services

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What data we access

  • With the account holder's authorization (OAuth), the tool accesses the authorized YouTube channel's ID and title, and the videos it uploads itself.
  • It uploads video files, titles, descriptions, tags, thumbnails and scheduled publish times that we created.
  • It does not access, collect or store data about any other YouTube users, viewers, comments or channels.

How we use, store and share data

  • OAuth tokens and the IDs of videos we uploaded are stored only on the operator's own computer, with access restricted to the operator's user account.
  • We do not sell, share or transfer any data to third parties, and we do not use it for advertising.
  • No cookies or tracking are used on this website.

Retention and deletion

  • Tokens are kept only while the tool is in use. You can revoke access at any time at Google Account → Security → Third-party access; we delete the stored token and any related data within 30 days of revocation or on request.
  • Stored API data is refreshed or deleted at least every 30 days, in line with the YouTube API Services Developer Policies.
